# Dibananeira — Landing Page

Landing page for **Dibananeira**, a handmade paper brand made from banana fibers. The site showcases the brand's story, products, and sustainability commitment with smooth animations and responsive design.

## Tech Stack

| | |
|---|---|
| **Framework** | React 19 + Vite 8 |
| **Animation** | animejs v4 (scroll-driven & continuous) |
| **Linting** | Oxlint |
| **Typography** | Georgia, serif |
| **Palette** | Earth tones — cream, brown, olive green |

## Sections

- **Hero** — decorative banana tree SVG + floating leaves
- **About** — brand story with scroll-triggered animation
- **Products** — card grid with animated hover
- **Sustainability** — animated stat counters
- **Contact** — form with animated input feedback
- **Footer** — links & credits

## Scripts

```bash
npm run dev      # development server
npm run build    # production build
npm run preview  # preview production build
npm run lint     # oxlint
```
